01

できること・できないこと

Aegis は、あやしいファイルとあやしい URL を見つけ、パソコンの守りが緩んでいないかを点検するためのアプリです。6 つのタブがそれぞれ独立した道具になっています。

タブ役割こんなときに
ファイル検査指定した場所のファイルを調べるUSB メモリを受け取った、心当たりのないファイルを見つけた
リアルタイム監視新しく増えたファイルをその場で調べる作業中ずっと見張らせておきたい
隔離ボックス取り出したファイルを安全に保管する消す前に一度よけておきたい、誤検出を戻したい
フィッシング判定URL やメール本文の詐欺らしさを採点する宅配の不在通知やカード会社を名乗るメールが届いた
システム診断Windows の保護設定を点検する守りが緩んでいないか定期的に確かめたい
自動起動の確認起動時に動くプログラムを一覧にするパソコンが重い、居座っているものがないか調べたい

できないこと

常駐型ウイルス対策ソフトの代わりにはなりません

Aegis はファイルを「開く前・実行される前」に自動で止める仕組み（カーネルレベルの常時保護）を持っていません。Microsoft Defender などの常駐ソフトは有効にしたまま、その上で使う補助的な道具としてお考えください。システム診断タブは、まさにその常駐保護が効いているかを確認するための機能です。

  • 感染したファイルの修復・駆除は行いません。できるのは隔離と削除です。
  • 検出は「あやしい特徴」からの推定です。正規のソフトが引っかかること（誤検出）もあります。いきなり削除せず、まず隔離してください。
  • ネットワークの通信内容やメールサーバーは見ません。判定はすべてこのパソコンの中だけで完結し、外部に何も送信しません。

動作環境とビルド

OSWindows 10（バージョン 1809 以降）/ Windows 11
フレームワーク.NET 8（デスクトップランタイム）
開発環境Visual Studio 2022 バージョン 17.8 以降 ＋「.NET デスクトップ開発」ワークロード
権限通常は不要。HKLM の自動起動の解除、システム領域のファイル隔離には管理者権限が必要

ビルドの手順

  1. ソリューションを開く配布された Aegis フォルダー内の Aegis.sln をダブルクリックします。
  2. パッケージを復元する初回ビルド時に NuGet から System.Management が自動で取得されます。社内ネットワークなどで取得できない場合は、プロキシ設定を確認してください。
  3. ビルドするメニューの「ビルド」→「ソリューションのビルド」を実行します。
  4. 実行するF5 キーで起動します。bin\Release\net8.0-windows\Aegis.exe を単体で配布することもできます。

コマンドラインからビルドする場合は次のとおりです。

dotnet build Aegis.sln -c Release
dotnet run --project Aegis/Aegis.csproj
配布用に 1 ファイルへまとめる

.NET ランタイムが入っていないパソコンでも動かしたい場合は、次のコマンドで自己完結型の実行ファイルを作れます。

dotnet publish Aegis/Aegis.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true

2 段構えの判定

1 つのファイルに対して、次の 2 つの検査が順に走ります。片方だけで判断せず、両方の結果を並べて表示します。

  1. ハッシュ照合（ルール ID: SIG） — ファイルの SHA-256 を計算し、定義ファイルに登録済みのものと突き合わせます。一致すれば確実です。ただし 1 バイトでも違えば一致しません。
  2. ヒューリスティック検査（R001〜R015） — 定義にないファイルでも、名前・構造・中身の特徴から怪しさを判断します。未知のものに強い代わりに、誤検出が起こりえます。

見つかったあとの操作

ボタン動作
選択したファイルを隔離隔離ボックスへ移します。元の場所からは消えますが、いつでも戻せます
保存場所を開くエクスプローラーでそのファイルを選択した状態で開きます
ハッシュを定義に追加そのファイルの SHA-256 をユーザー定義に登録し、次回から SIG ルールで即座に検出します
CSV で保存検出一覧を Excel などで開ける形式で書き出します

削除は取り消せませんが、隔離は取り消せます。判断に迷うファイルは隔離しておき、しばらく使ってみて困らなければ完全削除、必要だとわかったら復元、という順序が安全です。

誤検出が起こりやすいもの

次のようなファイルは、正規のものでも検出されることがあります。落ち着いて入手元を確かめてください。

  • R011（署名なし） — 個人が作ったツールやオープンソースソフトには署名がないことが普通にあります。
  • R010（高エントロピー） — インストーラーや圧縮された実行ファイルは、正規のものでもエントロピーが高くなります。
  • R009（マクロ） — 社内で配られる集計用の Excel にはマクロが入っていることがあります。差出人が確かなら問題ありません。
  • R005（一時領域） — インストール中のソフトが一時的に置いた正規ファイルの可能性があります。

逆に、R001・R002・R003・R014 が出た場合は、正規のソフトである可能性はほとんどありません。これらは偽装そのものが目的の作りだからです。

06

リアルタイム監視

指定したフォルダーを見張り、新しく現れたファイルをその場で検査します。ダウンロード直後や、USB メモリからコピーした直後の確認に向いています。

  1. フォルダーを決める起動時はダウンロード・デスクトップ・一時フォルダーが入っています。「監視フォルダを追加」で増やし、「選択したフォルダを外す」で減らせます。
  2. 自動隔離を決める危険度が高い検出を自動で隔離するかを選びます。既定はオフです。誤検出で必要なファイルが消えるのを避けたい場合はオフのままにしてください。
  3. 監視を開始する開始後は一覧に検出が新しい順で積まれます。危険度が高いものは、自動隔離がオフの場合に警告ダイアログでも知らせます。
監視の限界

監視はファイルが置かれた「あと」に働きます。書き込み中のファイルは完了を待ってから検査するため、数秒の遅れがあります。また、ファイルが実行されるのを止めることはできません。あくまで気づくための仕組みです。

アプリを閉じると監視も終了します。常に見張らせたい場合は、Aegis を起動したままにしておいてください。

07

隔離ボックス

隔離したファイルは %LOCALAPPDATA%\Aegis\Quarantine に移されます。保管時に全バイトを変換しているため、隔離中のファイルはダブルクリックしても実行されません。拡張子も .qbin に変わります。

ボタン動作取り消し
一覧を更新保管中のファイルを読み直します—
元に戻すもとのフォルダーへ、もとの形式で書き戻します再度隔離すれば戻せます
別の場所に取り出す保存先を選んで取り出します。調査用のコピーが欲しいときに同上
完全に削除保管データを消しますできません
隔離フォルダを開く保管場所をエクスプローラーで開きます—
復元は確認してから

「元に戻す」は、検出が誤りだったと確認できている場合にだけ使ってください。元の場所に同じ名前のファイルがある場合は、名前の末尾に _restored を付けて保存し、既存のファイルは上書きしません。

隔離に失敗する主な原因は、そのファイルが実行中であることと、権限が足りないことです。前者はいったん再起動してから、後者は「管理者として実行」してからお試しください。

フィッシング判定

入力欄に URL かメール本文を貼り付けて「判定する」を押します。1 行の URL だけならその URL を、複数行の文章なら文面と、その中に含まれるすべての URL を、それぞれ採点します。

50–74危険。開かない

メール本文で見ているもの

  • カード番号・暗証番号・ワンタイムパスワード・マイナンバーの要求（＋25）
  • アカウントの停止・制限・凍結をちらつかせる脅し（＋20）
  • リンクの表示名と実際のあて先が違う HTML リンク（＋35）
  • 「24 時間以内」「至急」など期限を切った催促（＋15）
  • 本人確認・再登録の要求、未払いや滞納の主張、宅配の不在通知、当選や還付金の知らせ（各＋15）

この判定は機械的な推定です。正規のメールが高く出ることも、巧妙な偽メールが低く出ることもあります。最後は次の 3 点で判断してください。

  • そのメールを自分が待っていたか
  • 同じ用件を、メールのリンクではなく公式アプリやブックマークから確認できるか
  • パスワードやカード番号を、メール経由で入力するよう求められていないか

すでに情報を入力してしまった場合は、そのサービスのパスワードをただちに変更し、カードや口座に関わるものならカード会社・銀行へ連絡してください。

「診断を実行」を押すと、Windows の保護設定を読み取って点検します。設定の書き換えは一切行いません。結果は危険・注意・不明・良好の順に並び、行を選ぶと右側に推奨される対処が出ます。

「Windows セキュリティを開く」ボタンから、対処のための設定画面へ直接移動できます。診断結果は「HTML レポート」で報告書として保存できます。

「不明」と出る項目について

Defender の状態など一部の項目は、読み取りに管理者権限が必要です。画面右上の「管理者として実行」で起動しなおすと取得できる場合があります。企業内で管理されたパソコンでは、グループポリシーによって読み取れないこともあります。

10

自動起動の確認

Windows の起動時に自動で動くプログラムを一覧にします。マルウェアは電源を切っても居座るために、ここへ自分を登録することがよくあります。

調べる場所

  • レジストリの Run / RunOnce（現在のユーザー分・コンピューター全体分・32 ビット互換分）
  • スタートアップフォルダー（個人用・全ユーザー用）

「要確認」と判定される特徴

所見なぜ疑わしいか
一時フォルダから起動しています正規のソフトは一時フォルダーに常駐しません
難読化されたコマンドが含まれています読ませたくない処理を隠している
スクリプト実行系のコマンドを使っていますPowerShell や mshta などを経由して本体を隠している
画面に表示せず起動する設定です気づかれないように動く意図がある
AppData 配下から起動しています権限が要らない場所で、マルウェアが好んで使う
実体のファイルが見つかりませんアンインストール後の残骸か、隠されている

操作

行を選んで「選択項目を検査」を押すと、そのプログラム本体をファイル検査と同じルールで調べます。不要と判断したら「自動起動から外す」で登録を解除できます。プログラム本体は削除されませんので、必要になれば手動で起動できます。

名前で調べてから消す

グラフィックドライバーやクラウドストレージの常駐など、正規のソフトも数多く登録されています。見覚えのない名前は、削除する前にその名前で検索して素性を確かめてください。コンピューター全体（HKLM）の項目を解除するには管理者権限が必要です。

11

ユーザー定義の書き方

# で始まる行はコメントとして読み飛ばされます。レベルは Low Medium High Critical のいずれかです。

# Aegis ユーザー定義ハッシュ
# 形式: <sha256>,<名前>,<Low|Medium|High|Critical>
275a021bbfb6489e54d471899f7db9d1663fc695ec2fe2a2c4538aabf651fd0f,EICAR-Test-File,Medium

検査結果の画面で行を選び「ハッシュを定義に追加」を押すと、このファイルに自動で追記されます。手で編集した場合は、アプリを起動しなおすと読み込まれます。

ハッシュ定義の性質

SHA-256 はファイルが 1 バイトでも違えば別の値になります。つまりハッシュ定義は「まったく同じファイル」しか見つけられません。少し書き換えられた亜種を捕まえるのはヒューリスティック検査の役目です。両方を有効にしておいてください。

12

動作テスト

検出が正しく働くかは、EICAR テストファイルで確かめられます。これはウイルス対策ソフトの動作確認のために業界団体が定めた無害なテキストファイルで、実際の被害を起こす機能は持っていません。

  1. テストファイルを用意するEICAR の公式サイト（eicar.org）から eicar.com を入手し、任意のフォルダーに置きます。
  2. そのフォルダーを検査する「フォルダを選んで検査」で指定します。
  3. 検出を確認するルール SIG、危険度「中」、名前「EICAR-Test-File」として一覧に出れば正常です。
常駐ソフトが先に反応します

Microsoft Defender などが有効な場合、ダウンロードや保存の時点でそちらが先に削除します。これは常駐保護が正しく働いている証拠です。Aegis のテストを行うときは、Defender の除外設定を一時的に加えるか、テストが終わったら設定を必ず元に戻してください。

フィッシング判定の動作は、テスト用の文字列で確かめられます。たとえば http://amazon.co.jp.secure-login.xyz/verify のような URL を入力すると、ブランドのなりすまし・注意が必要な TLD・ログイン誘導ワード・暗号化なしが同時に加点され、高い点数になります。

困ったときは

ビルド時に System.Management が見つからないと出る

NuGet パッケージの復元に失敗しています。Visual Studio のソリューションエクスプローラーでソリューションを右クリックし、「NuGet パッケージの復元」を実行してください。オフライン環境の場合は、あらかじめパッケージをローカルフィードに用意する必要があります。

システム診断で多くの項目が「不明」になる

読み取りに管理者権限が必要な項目です。画面右上の「管理者として実行」を押して起動しなおしてください。それでも取得できない場合は、企業のグループポリシーで制限されている可能性があります。

ファイルを隔離できない

原因は 2 つあります。1 つはそのファイルが実行中またはほかのアプリに開かれていること。タスクマネージャーで該当プロセスを終了するか、Windows を再起動してからお試しください。もう 1 つは権限不足で、Program Files などシステム領域のファイルは管理者権限が必要です。

ドライブ全体の検査が終わらない

ファイル数によっては数時間かかります。急ぐ場合は「中止」を押してください。そこまでの結果は残ります。日常的にはクイックスキャンで十分で、全体の検査は月に 1 回程度を目安にお考えください。

正規のソフトが検出されてしまう

R010（高エントロピー）や R011（署名なし）は、正規のソフトでも出ることがあります。入手元が信頼できるなら無視して構いません。検出そのものを減らしたい場合は「参考情報レベルも表示」のチェックを外してください。

リアルタイム監視が反応しない

大量のファイルが一度に作られると、Windows 側の通知が取りこぼされることがあります。ネットワークドライブや仮想ドライブも監視できない場合があります。監視対象は、ダウンロードやデスクトップなど、ファイルが増える場所に絞るのが確実です。

アプリ自体が起動しない

.NET 8 デスクトップランタイムが入っていない可能性があります。Microsoft のダウンロードページから「.NET Desktop Runtime 8」を導入してください。それでも起動しない場合は %LOCALAPPDATA%\Aegis\aegis.log の末尾を確認すると原因の手がかりが得られます。

本当に感染したかもしれないときは

Aegis での作業を続けるより先に、ネットワークから切り離し（LAN ケーブルを抜く、Wi-Fi をオフにする）、Microsoft Defender のオフラインスキャンを実行してください。金銭やアカウントに関わる情報を入力していた場合は、別の安全な端末からパスワードを変更し、関係する事業者へ連絡してください。

用語意味
SHA-256ファイルの中身から計算する 64 桁の値。中身が同じなら必ず同じ値になり、1 バイトでも違えば別の値になる
ハッシュ照合SHA-256 を既知の脅威のリストと突き合わせる検査方法。確実だが、同一のファイルしか見つけられない
ヒューリスティック検査ファイルの形や中身の特徴から怪しさを推定する検査方法。未知のものに強いが、誤検出が起こりうる
エントロピーデータの乱雑さを 0〜8 で表した数値。圧縮や暗号化を施すと 8 に近づく
PE 形式Windows の実行ファイルの構造。先頭が MZ の 2 文字で始まる
RLO文字の並びを右から左へ反転させる制御文字。gpj.exe を exe.jpg のように見せかけるのに悪用される
Punycode日本語などの文字を含むドメインを英数字で表す方式。xn-- で始まる。見た目が似た文字での偽装に使われる
タイポスクワッティング正規ドメインと 1〜2 文字違いのドメインを取得し、打ち間違いや見間違いを狙う手口
TLDドメインの末尾部分（.com .jp など）。登録が容易な一部の TLD は詐欺に多用される
Mark of the Webインターネットから取得したファイルに Windows が付ける印。Office などはこの印を見て保護ビューを働かせる
デジタル署名ソフトの発行元を証明する電子的な署名。署名があれば、配布後に改ざんされていないことが確かめられる
シャドウコピーWindows がファイルの過去の状態を保持する仕組み。ランサムウェアは復旧を妨げるためにこれを削除しようとする
SMBv1古いファイル共有の通信方式。深刻な脆弱性があり、ランサムウェアの拡散に悪用された経緯がある
