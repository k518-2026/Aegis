# Aegis セキュリティスイート

実行ファイルのダウンロード.
https://github.com/k518-2026/Aegis/releases

Windows 向けの「ウイルスチェック / マルウェア対策 / フィッシング対策」デスクトップアプリです。
WPF（C# / .NET 8）で作られており、Visual Studio 2022 で `Aegis.sln` を開けばそのままビルドできます。

---

## ビルド方法

1. Visual Studio 2022（17.8 以降）を開く
2. `Aegis.sln` を開く
3. 初回はメニューの「ビルド」→「ソリューションのビルド」（NuGet から `System.Management` が自動復元されます）
4. F5 で実行

必要なもの: **.NET 8 SDK**（Visual Studio インストーラーの「.NET デスクトップ開発」ワークロード）

コマンドラインの場合:

```
dotnet build Aegis.sln -c Release
dotnet run --project Aegis/Aegis.csproj
```

## 画面と機能

### 1. ファイル検査
- **クイックスキャン** … デスクトップ / ダウンロード / 一時フォルダ / スタートアップを検査
- フォルダ・ファイル・ドライブ全体の指定検査
- 判定は 2 段構え
  - **ハッシュ照合**: SHA-256 が定義ファイルと一致するか
  - **ヒューリスティック検査**: 未知のファイルでも「怪しい形」を見つける（下表）
- 検出したファイルは**隔離**、ハッシュの**定義追加**、CSV / HTML レポート出力ができます

| ID | 検出内容 |
|----|----------|
| R001 | RLO 制御文字によるファイル名の表示偽装 |
| R002 | 二重拡張子（例: 請求書.pdf.exe） |
| R003 | 拡張子は文書・画像なのに中身が実行ファイル（PE 形式） |
| R004 | .scr / .pif / .hta など攻撃で好まれる形式 |
| R005 | 一時フォルダ・ダウンロード内の実行ファイル |
| R006 | スクリプト内の危険な処理（難読化実行、外部からのダウンロード実行、シャドウコピー削除、保護の無効化など） |
| R007 | 1 行が極端に長い難読化コード |
| R008 | PowerShell 等を起動するショートカット（.lnk） |
| R009 | VBA マクロ入りの Office 文書 |
| R010 | エントロピーが高い（パック・暗号化された）実行ファイル |
| R011 | デジタル署名のない実行ファイル |
| R012 | インターネット由来のマーク（Zone.Identifier）付き実行ファイル |
| R013 | 隠し属性の実行ファイル |
| R014 | svchost などシステムプロセス名の詐称 |
| R015 | 空白で拡張子を画面外に隠すファイル名 |

### 2. リアルタイム監視
`FileSystemWatcher` で指定フォルダを見張り、新しく現れたファイルをその場で検査します。
危険度が高いものを自動隔離するオプション付き（既定はオフ）。

### 3. 隔離ボックス
隔離したファイルは全バイトを XOR 変換して `%LOCALAPPDATA%\Aegis\Quarantine` に保管するため、
そのままでは実行されません。誤検出だった場合は「元に戻す」で復元できます。

### 4. フィッシング判定
URL やメール本文を貼り付けると、点数で危険度を示します。**判定はすべて端末内で完結**し、外部送信はありません。

- ドメイン系: IP 直指定 / Punycode / 文字体系の混在 / `@` による偽装 / 危険な TLD / 短縮 URL / サブドメインの深さ
- ブランド系: 有名サービス名を含むのに公式ドメインではない、正規ドメインと 1〜2 文字違いの「そっくりドメイン」
- 文面系: アカウント停止の脅し、期限を切った催促、本人確認の要求、カード番号や暗証番号の要求、宅配不在通知の偽装、リンクの表示名と実際のあて先の不一致

### 5. システム診断
Windows の保護設定を**読み取りのみ**で点検します（書き換えはしません）。

Defender のリアルタイム保護と定義の鮮度 / 登録済みウイルス対策製品 / ファイアウォール（3 プロファイル）/
SmartScreen / UAC / Windows Update の最終適用 / hosts ファイルの改ざん / リモートデスクトップ /
SMBv1 / PowerShell 実行ポリシー / 自動再生 / 拡張子の表示 / OS バージョン

### 6. 自動起動の確認
Run / RunOnce レジストリとスタートアップフォルダを一覧化し、
一時フォルダからの起動・難読化コマンド・署名なしなどを「要確認」として色分けします。不要な項目はその場で解除できます。

## ハッシュ定義の追加

`Aegis\Resources\signatures.json` が同梱の定義です。ユーザー追加分は次のファイルに 1 行 1 件で書けます。

```
%LOCALAPPDATA%\Aegis\user-signatures.txt

<sha256>,<名前>,<Low|Medium|High|Critical>
```

検査結果の画面から「ハッシュを定義に追加」ボタンでも追記できます。

動作確認には **EICAR テストファイル**（業界標準の無害な検査用ファイル）が使えます。
同梱の定義に SHA-256 を登録済みなので、EICAR を置いたフォルダを検査すると `SIG` ルールで検出されます。

## アイコン

`Aegis\Resources\aegis.ico` がアプリのアイコンです（16 / 20 / 24 / 32 / 48 / 64 / 128 / 256 px の 8 サイズを収録）。
`ApplicationIcon` として exe に埋め込まれ、ウィンドウの左上とタスクバーにも表示されます。

作り直したい場合は同じフォルダーの `make_icon.py` を実行してください（要 Python + Pillow）。
配色や形はスクリプト冒頭の定数で変更できます。`aegis-256.png` は Web やドキュメント用の書き出しです。

```
pip install pillow
python Aegis/Resources/make_icon.py
```

## 注意

- 本アプリは**補助的なチェックツール**です。常駐型ウイルス対策ソフト（Microsoft Defender など）の置き換えにはなりません。両方を併用してください。
- 検出は「疑わしい特徴」に基づく推定です。正規のソフトが検出されること（誤検出）もあります。削除の前に必ず隔離を使ってください。
- HKLM の自動起動項目の変更、システム領域のファイル隔離には管理者権限が必要です。画面右上の「管理者として実行」から昇格できます。
- ログは `%LOCALAPPDATA%\Aegis\aegis.log` に出力されます。

## ClamAV で検査（2026-11-02 から。旧 VirusScannerApp を統合）

「ClamAV で検査」タブから、オープンソースのウイルス対策エンジン **ClamAV**（Cisco Systems、GPL-2.0）で
フォルダーを検査できます。Aegis 自身の検査（ハッシュ定義・ヒューリスティック）とは別の、外部のエンジンです。

- **ClamAV 本体は Aegis.exe に入っていません**（DLL が約 70 MB、定義ファイルが約 300 MB あるため）。次の順に探します
  1. Aegis.exe と同じフォルダーの `ClamAV\`（または `ClamAV_Engine\`）
  2. 「ClamAV の場所を選ぶ…」で指定したフォルダー（次回も覚えます）
  3. `C:\Program Files\ClamAV`（公式インストーラーの既定の場所）
- 「定義ファイルを更新」で `freshclam.exe` を動かし、`database.clamav.net` から定義を取得します（初回は約 300 MB）。
  定義はエンジンの隣の `database\` に置きます。そこに書けないときは `%LOCALAPPDATA%\Aegis\clamav-db` に置きます
- 「フォルダーを検査…」で `clamscan.exe -r` を動かし、進み具合と検出を一覧に出します。途中で中止できます
- 検出したファイルは「選んだものを隔離」で、Aegis の隔離ボックスへ移せます（元に戻せます）
- 公式の定義（.cvd/.cld/.cud）のほか、自分で作った定義（.hdb/.hsb/.ndb/.ldb）を `database\` に置いても使えます

確認したこと: 自作のハッシュ定義（.hdb）で、日本語・空白を含むパスのファイルを検出できること、22 件の件数、終了コード、中止を確認しました。
公式の定義ファイルのダウンロード（freshclam）は、約 300 MB の通信になるため未実施です。
